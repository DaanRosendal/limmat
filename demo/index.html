Streaming markdown that never shows a half-finished marker.

limmat renders LLM replies into the DOM as they arrive. It is about 7 kB gzip, has no dependencies, and shows raw HTML as text. Below, you can break it yourself.

npm install limmat

The left pane is exactly what the model sends, in the chunks you choose. The right pane is limmat's output after every chunk. Only the open block (outlined) is touched, and finished blocks stay still.
